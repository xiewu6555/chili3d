# 🚀 快速开始指南

欢迎使用BREP模型数据标注软件！本指南将帮助您在5分钟内完成第一个加工特征标注。

- ✅ 稳定的网络连接
- ✅ 至少4GB可用内存

## 🎯 5分钟快速教程

### 第1步：启动软件 (30秒)

1. 打开浏览器，访问 chili3d 应用
2. 等待界面加载完成
3. 点击工具栏中的"启动标注"按钮
   ```
   📍 位置：顶部工具栏 → "Start Annotation" 按钮
   ```

### 第2步：加载模型 (30秒)

1. 点击 **File → Open** 或使用快捷键 `Ctrl+O`
2. 选择您的STEP文件
3. 等待模型加载到3D视图中
4. 使用鼠标调整视角：
   - 🖱️ **左键拖拽**：旋转视图
   - 🖱️ **中键拖拽**：平移视图  
   - 🖱️ **滚轮**：缩放视图

### 第3步：创建第一个标注 (2分钟)

#### 标注一个通孔特征

1. **选择特征类型**
   - 在右侧标注面板找到"特征类型选择器"
   - 下拉选择 **"Through Hole (通孔)"**

2. **创建新标注**
   - 点击 **"创建新标注"** 按钮
   - 系统自动生成名称如 "ThroughHole_001"

3. **选择相关面**
   - 在3D视图中单击孔的圆柱内表面
   - 选中的面会以绿色高亮显示
   - 面板显示"选中面：1"

4. **添加面到标注**
   - 点击 **"添加选中面"** 按钮
   - 活动标注信息更新显示"面数：1"

5. **确认标注**
   - 点击 **"确认标注"** 按钮
   - 如有验证错误，根据提示修正

🎉 **恭喜！** 您已经完成了第一个特征标注！

### 第4步：验证和导出 (2分钟)

1. **验证标注**
   ```
   Tools → Annotation → Validate All
   ```
   - 绿色提示：验证通过
   - 红色提示：有错误需要修正

2. **导出结果**
   - 点击标注面板底部的 **"Export AAGNet"** 按钮
   - 文件自动下载到您的下载文件夹
   - 文件名类似：`annotations_aagnet_1234567890.json`

3. **查看结果**
   - 打开下载的JSON文件
   - 您会看到如下结构的标注数据：
   ```json
   [
     [
       "your-model.step",
       {
         "seg": { "0": 2 },
         "inst": [[1, 0], [0, 1]],
         "bottom": { "0": 0 }
       }
     ]
   ]
   ```

## 💡 常用操作技巧

### 🖱️ 面选择技巧
```
单击        → 选择单个面
Ctrl+单击   → 多选/取消选择
Shift+单击  → 范围选择
Esc        → 清除所有选择
```

### ⌨️ 快捷键
```
Ctrl+A     → 启动标注模式
Ctrl+N     → 创建新标注
Ctrl+S     → 保存标注
Ctrl+E     → 导出标注
Ctrl+Z     → 撤销操作
Ctrl+Y     → 重做操作
Space      → 确认当前操作
Delete     → 删除选中内容
```

### 🎨 视图控制
```
F+N        → 显示/隐藏面编号
V+H        → 隐藏选中面
V+S        → 显示所有面
A+1        → 显示所有标注
A+2        → 只显示活动标注
```

## 📚 进阶示例

### 示例1：标注矩形凹槽

1. 选择特征类型：**"Rectangular Pocket"**
2. 选择面：凹槽底面 + 所有侧壁面（通常5个面）
3. 设置参数：长度、宽度、深度

```
💡 提示：矩形凹槽通常需要选择5个面
- 1个底面
- 4个侧壁面
```

### 示例2：标注倒角特征

1. 选择特征类型：**"Chamfer"**
2. 选择面：倒角面本身（通常1个面）
3. 设置参数：倒角距离或角度

```
💡 提示：倒角特征通常只需要选择倒角面本身
```

### 示例3：批量标注相似特征

1. 完成第一个特征的标注
2. 右键点击已标注特征 → **"Find Similar"**
3. 系统自动识别相似特征
4. 逐个确认并创建标注

## ❓ 常见问题解答

### Q: 面选择不准确怎么办？
**A: 尝试以下方法：**
- 调整视角，使目标面清晰可见
- 放大视图以便精确选择
- 使用面编号辅助（F+N）
- 临时隐藏遮挡面（右键→Hide）

### Q: 验证失败的常见原因？
**A: 检查以下项目：**
- ✓ 面数量是否符合特征类型要求
- ✓ 是否有面被重复分配
- ✓ 标注名称是否符合规范
- ✓ 几何参数是否设置正确

### Q: 导出的文件在哪里？
**A:** 
- 默认保存在浏览器的下载文件夹
- 文件名格式：`annotations_[格式]_[时间戳].json`
- 可以在浏览器下载历史中查看

### Q: 如何修改已创建的标注？
**A:**
1. 在标注列表中点击要修改的标注
2. 该标注成为活动标注
3. 可以添加/删除面，修改参数
4. 重新确认标注

### Q: 软件运行缓慢怎么办？
**A: 优化建议：**
- 关闭其他浏览器标签页
- 降低模型显示精度
- 使用硬件加速
- 分批处理复杂模型
