## 系统概述

### 功能特色
- 支持27种加工特征类型的精确标注
- 直观的3D可视化界面和面选择交互
- 双导出格式（AAGNet、MFTRCAD）满足不同训练需求
- 完整的验证系统确保标注质量
- 历史记录功能支持撤销/重做操作

### 支持的文件格式
- **输入**: STEP文件（.step, .stp）
- **输出**: JSON格式标注文件（AAGNet/MFTRCAD）

### 系统要求
- **操作系统**: Windows 10+, macOS 10.15+, Linux Ubuntu 18.04+

### 标注面板详解

#### 1. 特征类型选择器
- **位置**: 面板顶部
- **功能**: 选择要创建的加工特征类型
- **支持类型**: 
  - 基本特征: 倒角、圆角、通孔、盲孔
  - 凹槽特征: 矩形凹槽、三角形凹槽、六边形凹槽、圆形凹槽
  - 槽特征: 矩形通槽、三角形通槽、圆形通槽
  - 其他特征: 详见完整特征列表

#### 2. 活动标注信息区
- 显示当前选中标注的详细信息
- 包括标注名称、特征类型、关联面数量
- 实时更新选中面信息

#### 3. 操作按钮组
- **创建新标注**: 基于选定特征类型创建标注
- **添加选中面**: 将当前选中的面添加到活动标注
- **确认标注**: 验证并确认当前标注
- **删除标注**: 删除当前活动标注

#### 4. 标注列表
- 显示所有已创建的标注
- 点击标注名称可切换活动标注
- 不同颜色表示不同状态（活动/非活动）

#### 5. 导出功能区
- **导出AAGNet**: 导出为AAGNet格式JSON文件
- **导出MFTRCAD**: 导出为MFTRCAD格式JSON文件

## 标注工作流程

### 步骤1: 加载STEP模型

1. **打开文件**
   ```
   File → Open → 选择.step或.stp文件
   ```

2. **模型加载确认**
   - 等待模型在3D视图中完全加载
   - 确认所有面都正确显示
   - 使用鼠标进行视图操作：
     - 左键拖拽：旋转视图
     - 中键拖拽：平移视图
     - 滚轮：缩放视图

3. **启动标注模式**
   ```
   Tools → Annotation → Start Annotation Mode
   ```
   或使用快捷键 `Ctrl+A`

### 步骤2: 创建特征标注

1. **选择特征类型**
   - 在标注面板中选择合适的特征类型
   - 例如：为圆孔选择"Through Hole"或"Blind Hole"

2. **创建新标注**
   - 点击"创建新标注"按钮
   - 系统自动生成标注名称（可后续修改）
   - 新标注成为当前活动标注

### 步骤3: 选择相关面

#### 基本选择操作
```
单击面：选择单个面
Ctrl + 单击：多选面（切换选中状态）
Shift + 单击：范围选择（选择从上次选中到当前的所有面）
Esc：清除所有选择
```

#### 面选择技巧
1. **孔特征选择**：
   - 通孔：选择圆柱内表面
   - 盲孔：选择圆柱内表面 + 底面

2. **槽特征选择**：
   - 选择所有槽的内表面
   - 包括底面和所有侧面

3. **凹槽选择**：
   - 选择凹槽的底面
   - 选择所有侧壁面

4. **倒角/圆角选择**：
   - 选择倒角或圆角表面本身

#### 选择确认
- 选中的面会以绿色高亮显示
- 面板显示当前选中的面数量和ID
- 确认选择正确后点击"添加选中面"

### 步骤4: 设置几何参数

1. **基本参数设置**
   - 双击标注列表中的标注名称
   - 在弹出窗口中设置几何参数：
     ```
     孔特征：直径、深度（盲孔）
     槽特征：长度、宽度、深度
     倒角：距离、角度
     圆角：半径
     ```

2. **公差设置**（可选）
   - 设置尺寸公差：上偏差、下偏差
   - 设置对称公差：±值

### 步骤5: 验证标注

1. **自动验证**
   - 添加面后系统自动进行基础验证
   - 红色标记表示验证错误
   - 黄色标记表示验证警告

2. **手动验证**
   ```
   Tools → Annotation → Validate All
   ```
   
3. **验证内容**
   - **基本验证**: 标注名称、特征类型、面数量
   - **拓扑验证**: 面唯一性、连通性
   - **几何验证**: 参数合理性、尺寸约束

### 步骤6: 确认标注

1. **确认操作**
   - 点击"确认标注"按钮
   - 系统将对标注进行最终验证

2. **错误处理**
   - 如有错误，根据提示修正
   - 常见错误：
     - 面数量不符合特征要求
     - 几何参数缺失或不合理
     - 面重复分配给多个标注

### 步骤7: 导出结果

1. **选择导出格式**
   - **AAGNet格式**: 适用于AAGNet模型训练
   - **MFTRCAD格式**: 适用于MFTRCAD模型训练

2. **执行导出**
   - 点击相应的导出按钮
   - 文件自动下载到默认下载目录
   - 文件命名格式：`annotations_[格式]_[时间戳].json`

## 高级功能

### 批量操作

#### 批量选择相似特征
1. **选择参考特征**：右键点击已标注的特征
2. **查找相似特征**：选择"Find Similar Features"
3. **批量标注**：确认相似特征后批量创建标注

#### 相邻面选择
```
选择基础面 → 右键菜单 → Select Adjacent Faces
```

### 历史记录操作

#### 撤销/重做
```
Ctrl + Z：撤销上一步操作
Ctrl + Y：重做操作
```

#### 历史记录查看
```
View → History Panel
```
- 查看所有操作历史
- 点击任意历史节点跳转到该状态

### 视图控制

#### 显示/隐藏功能
```
V + H：隐藏选中面
V + S：显示所有面
V + I：反选显示
```

#### 标注可视化
```
A + 1：显示所有标注
A + 2：只显示活动标注
A + 3：隐藏标注显示
```

#### 面编号显示
```
F + N：显示/隐藏面编号
```

### 数据管理

#### 自动保存
- 系统每30秒自动保存标注数据到本地
- 数据保存在浏览器localStorage中

#### 手动保存/加载
```
File → Save Annotations：保存当前标注
File → Load Annotations：加载之前的标注
```

## 常见问题

### Q1: 模型加载失败
**问题**: STEP文件无法正确加载或显示不完整

**解决方案**:
1. 确认文件格式为标准STEP格式
2. 检查文件大小（建议小于100MB）
3. 尝试在CAD软件中重新导出STEP文件
4. 确认文件路径不包含中文字符

### Q2: 面选择困难
**问题**: 无法准确选择所需的面

**解决方案**:
1. 调整视角，使目标面清晰可见
2. 使用缩放功能放大细节区域
3. 临时隐藏遮挡的面（右键→Hide）
4. 使用面编号辅助选择（F+N）

### Q3: 标注验证失败
**问题**: 标注无法通过验证

**常见原因及解决**:
- **面数量错误**: 检查特征类型要求的面数量
- **重复面分配**: 确保每个面只分配给一个标注
- **几何参数缺失**: 设置必要的几何参数
- **参数值不合理**: 检查尺寸参数是否符合实际情况

### Q4: 导出文件格式问题
**问题**: 导出的JSON文件格式不正确

**解决方案**:
1. 确认所有标注都已验证通过
2. 检查是否存在未完成的标注
3. 尝试重新启动标注模式
4. 联系技术支持提供详细错误信息

### Q5: 性能问题
**问题**: 大模型处理缓慢

**优化建议**:
1. 关闭不必要的浏览器标签页
2. 使用专用显卡进行硬件加速
3. 适当降低模型显示精度
4. 分批处理复杂模型

## 最佳实践

### 标注质量保证

1. **命名规范**
   ```
   特征类型_序号_描述
   例如：ThroughHole_001_MainShaft
        RectPocket_002_CoolantChannel
   ```

2. **面选择原则**
   - **完整性**: 选择构成特征的所有相关面
   - **准确性**: 确保选择的面确实属于该特征
   - **一致性**: 同类特征使用相同的选择标准

3. **几何参数设置**
   - 使用实际测量值，避免估算
   - 设置合理的公差范围
   - 对关键尺寸添加备注说明

### 工作效率提升

1. **快捷键使用**
   ```
   Ctrl + A：启动标注模式
   Ctrl + N：创建新标注
   Ctrl + S：保存标注
   Ctrl + E：导出标注
   Space：确认当前操作
   ```

2. **模板应用**
   - 为常用特征创建标注模板
   - 保存典型的几何参数设置
   - 批量应用相似特征标注

3. **分阶段标注**
   ```
   第一阶段：标注主要特征（孔、槽等）
   第二阶段：标注次要特征（倒角、圆角）
   第三阶段：验证和优化
   ```

### 质量控制流程

1. **自检清单**
   - [ ] 所有面都已正确选择
   - [ ] 几何参数设置合理
   - [ ] 标注名称规范
   - [ ] 通过所有验证测试

2. **交叉验证**
   - 与原始CAD模型对比
   - 使用不同视角检查标注
   - 导出后检查JSON格式正确性

3. **版本管理**
   - 定期保存标注文件
   - 记录重要修改的版本号
   - 备份关键标注数据
