## 📊 功能特性一览

### ✨ 核心功能
- ✅ **27种加工特征类型** - 全面覆盖CNC加工特征
- ✅ **双导出格式** - AAGNet和MFTRCAD格式
- ✅ **三层验证系统** - 标注、拓扑、几何验证
- ✅ **交互式3D界面** - 直观的面选择和标注操作
- ✅ **历史记录** - 完整的撤销/重做功能

### 🎯 支持的特征类型

| 类别 | 特征类型 | 数量 |
|------|----------|------|
| **基础特征** | 倒角、圆角、通孔、盲孔等 | 8种 |
| **凹槽特征** | 矩形、三角、圆形、六边形凹槽 | 6种 |  
| **槽特征** | 直槽、T槽、燕尾槽等 | 7种 |
| **其他特征** | 锥面、螺纹、键槽等 | 6种 |
| **总计** | | **27种** |

### 🔄 导出格式

| 格式 | 用途 | 结构特点 |
|------|------|----------|
| **AAGNet** | AAGNet模型训练 | 邻接矩阵表示实例关系 |
| **MFTRCAD** | MFTRCAD模型训练 | 列表形式表示特征实例 |
| **自定义** | 扩展支持 | 可自定义导出格式 |

## 🛠️ 系统要求

### 最低配置
- **操作系统**: Windows 10+, macOS 10.15+, Ubuntu 18.04+
- **浏览器**: Chrome 90+, Firefox 88+, Edge 90+
- **内存**: 4GB RAM
- **存储**: 500MB 可用空间

### 推荐配置  
- **内存**: 8GB+ RAM
- **显卡**: 独立显卡支持WebGL 2.0
- **CPU**: 4核心以上处理器
- **网络**: 稳定的互联网连接

### 支持的文件格式
- **输入**: STEP (.step, .stp), IGES (.igs, .iges)
- **输出**: JSON (.json), XML (.xml)
