## 系统介绍

BREP模型标注系统是专门为3D CAD模型机加工特征标注而设计的工具。该系统支持27种标准机加工特征类型的识别、标注和验证，广泛应用于学术研究和工业生产。

### 主要用途

- **学术研究**: 为机器学习和特征识别算法提供标准化训练数据
- **工业应用**: 支持CAD/CAM工艺规划和制造工程
- **质量控制**: 验证机加工特征的准确性和完整性
- **数据交换**: 提供标准格式的特征数据导出

### 支持的文件格式

- **输入格式**: STEP, IGES, STL等标准3D CAD格式
- **输出格式**: AAGNet（学术标准）, MFTRCAD（工业标准）

## 快速开始

### 前置条件

1. 确保chili3d应用程序正常运行
2. 已加载需要标注的3D模型文件
3. 模型具有清晰的面几何结构

### 5分钟快速标注

#### 步骤1: 启动标注模式

1. 在chili3d界面中找到标注工具栏
2. 点击 **"启动标注"** 按钮
3. 系统会在屏幕右侧显示标注面板

```
✅ 成功提示:
"标注模式已成功启动！
✓ 标注管理器已创建
✓ 面选择功能已激活  
✓ 标注面板已显示"
```

#### 步骤2: 创建第一个标注

1. 在标注面板的 **"Feature Type"** 下拉菜单中选择特征类型
   - 例如：选择 "Through Hole (通孔)"
2. 点击 **"Create New Annotation"** 按钮
3. 系统会创建新标注并设为活动状态

#### 步骤3: 选择和添加面

1. 点击 **"Select Faces"** 按钮进入面选择模式
2. 在3D视图中直接点击要标注的面
   - 可以连续点击多个面
   - 无需按住Ctrl键
3. 按 **Esc** 键完成面选择
4. 点击 **"Add Selected Faces"** 按钮将选中的面添加到标注

#### 步骤4: 完成标注

1. 点击 **"Confirm Annotation"** 按钮确认标注
2. 系统会自动验证标注的完整性
3. 验证通过后，标注创建完成

#### 步骤5: 导出数据（可选）

1. 点击 **"Export AAGNet"** 或 **"Export MFTRCAD"** 按钮
2. 选择保存位置和文件名
3. 导出完成

## 机加工特征类型

### 特征分类概览

#### 孔类特征 (Hole Features)

**1. 通孔 (Through Hole)**
- **描述**: 完全穿透零件的圆形孔
- **典型面数**: 1个圆柱面
- **应用**: 螺栓连接，轴承安装

**2. 盲孔 (Blind Hole)**  
- **描述**: 不完全穿透的圆形孔
- **典型面数**: 1个圆柱面 + 1个底面
- **应用**: 螺纹孔，定位孔

#### 槽类特征 (Slot Features)

**3. 矩形通槽 (Rectangular Through Slot)**
- **描述**: 矩形截面的通槽
- **典型面数**: 4个侧面
- **应用**: 键槽，导轨槽

**4. 圆形通槽 (Circular Through Slot)**
- **描述**: 圆形截面的通槽  
- **典型面数**: 1个圆柱面
- **应用**: O型圈槽，密封槽

#### 台阶特征 (Step Features)

**5. 矩形通阶 (Rectangular Through Step)**
- **描述**: 矩形台阶特征
- **典型面数**: 2-5个面
- **应用**: 轴肩，定位台阶

#### 其他特征

**6. 倒角 (Chamfer)**
- **描述**: 边缘倒角面
- **典型面数**: 1个斜面
- **应用**: 去毛刺，装配引导

**7. 圆角 (Round)**
- **描述**: 边缘圆角面
- **典型面数**: 1个圆角面  
- **应用**: 应力集中消除，美观

### 特征选择指南

#### 根据几何形状选择

```
圆形几何:
├── 穿透 → Through Hole
├── 不穿透 → Blind Hole
└── 槽形 → Circular Through Slot

矩形几何:
├── 通过型 → Rectangular Through Slot
├── 凸台型 → Rectangular Pocket  
└── 台阶型 → Rectangular Through Step

边缘处理:
├── 直线倒角 → Chamfer
└── 圆弧过渡 → Round
```

#### 根据加工工艺选择

- **钻孔工艺**: Through Hole, Blind Hole
- **铣削工艺**: Rectangular Slot, Pocket系列
- **车削工艺**: Cylinder, Cone, Round
- **后处理**: Chamfer, Round

## 故障排除

### 常见问题

#### 问题1: 标注面板不显示

**症状**: 点击"启动标注"后面板未出现

**可能原因**:
- DOM容器未正确找到
- 样式冲突
- JavaScript错误

**解决方案**:
1. 检查浏览器控制台是否有错误
2. 确保chili3d应用正常加载
3. 尝试刷新页面重新启动

```javascript
// 手动检查面板
const panel = document.querySelector('.annotation-panel');
if (!panel) {
    console.log('标注面板未找到，请重新启动标注模式');
}
```

#### 问题2: 面选择无响应

**症状**: 点击3D模型面无反应

**可能原因**:
- 面选择处理器未激活
- Canvas事件监听器未正确设置
- 3D视图不支持拾取

**解决方案**:
1. 确认标注模式已启动
2. 检查控制台是否有"找到3D视图canvas"的消息
3. 尝试使用键盘快捷键测试

```javascript
// 检查面选择状态
const handler = document._faceSelectionHandler;
console.log('面选择器状态:', handler?.isActive);
```

#### 问题3: 验证失败

**症状**: 添加面或确认标注时提示验证失败

**常见验证错误**:
- 面ID无效或重复
- 特征类型约束不满足
- 标注信息不完整

**解决方案**:
1. 检查错误提示的具体内容
2. 确认面选择正确
3. 检查特征类型是否匹配实际几何

```
常见约束:
- 通孔: 需要1-3个面
- 凸台: 至少2个面
- 倒角: 通常1个面
```

#### 问题4: 导出失败

**症状**: 点击导出按钮无反应或报错

**可能原因**:
- 没有标注可导出
- 标注数据不完整
- 浏览器权限限制

**解决方案**:
1. 确认已创建并验证标注
2. 检查浏览器下载设置
3. 尝试手动保存导出的JSON数据

### 错误代码参考

#### E001: 标注管理器初始化失败
```
错误: 无法创建标注管理器
解决: 确保有活动文档，重启标注模式
```

#### E002: 面选择器激活失败  
```
错误: 面选择处理器无法激活
解决: 检查3D视图状态，重新加载页面
```

#### E003: 验证器错误
```
错误: 标注验证失败
解决: 检查标注数据完整性，修复错误字段
```

### 性能问题

#### 大模型处理

**症状**: 大型模型标注响应缓慢

**优化方案**:
1. 减少同时显示的标注数量
2. 使用LOD（细节级别）渲染
3. 分批处理面选择

#### 内存占用过高

**症状**: 长时间使用后系统变慢

**解决方案**:
1. 定期清理标注历史
2. 释放不用的标注实例
3. 重启标注模式

```javascript
// 清理内存
manager.dispose();
manager = new AnnotationManager(document);
```

```
   └── 确认面结构清晰

2. 特征识别
   ├── 分析模型几何特征
   ├── 制定标注计划
   └── 确定特征优先级

3. 分类标注  
   ├── 先标注主要特征
   ├── 再处理细节特征
   └── 最后处理边缘处理特征

4. 验证确认
   ├── 逐个验证标注
   ├── 检查覆盖完整性
   └── 确认特征类型正确

5. 数据导出
   ├── 选择合适格式
   ├── 验证导出数据
   └── 保存备份
```

### 标注质量控制

#### 标注一致性

1. **命名规范**: 使用统一的命名约定
   ```
   特征类型_序号_描述
   例: ThroughHole_001_M8
       Chamfer_002_2mm
   ```

2. **分类准确**: 确保特征类型选择正确
   - 仔细观察几何形状
   - 考虑加工工艺
   - 参考技术图纸

3. **面选择完整**: 包含特征的所有相关面
   - 主要功能面
   - 过渡面
   - 底面（如适用）

#### 验证检查清单

```
✓ 基本信息
  ├── 标注名称有意义
  ├── 特征类型正确
  └── 创建信息完整

✓ 几何数据  
  ├── 面选择完整
  ├── 面ID有效
  └── 无重复标注

✓ 约束满足
  ├── 面数量合理
  ├── 几何约束满足
  └── 拓扑关系正确

✓ 数据完整性
  ├── 所有特征已标注
  ├── 标注覆盖充分
  └── 无遗漏特征
```
